# Contributing

Thanks for helping! Issues and pull requests in English or Turkish are both fine.

1. **Bugs:** open an issue with the input, what you got, and what you expected.
2. **New functions:** open an issue first so we can agree on the name and behaviour.
3. **Pull requests:** keep them small, add a test in `test/index.test.js`, and run `npm test` (Node 18+, nothing to install).

The package has no dependencies and must not depend on `Intl` or the runtime locale. Please keep it that way.
